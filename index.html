ช่วยเขียนโค้ดสร้าง Web App AI ส่วนตัวแบบ Single-file (HTML/CSS/JavaScript รวมในไฟล์เดียว) ที่มีดีไซน์สวยงาม หรูหรา เรียบหรูในสไตล์ "Luxury Black & Gold" (ธีมสีดำตัดทองคำ ดำเงา Deep Charcoal/Obsidian ตัดกับโทนสีทอง Metallic Gold/Warm Gold) รองรับการใช้งานทั้งบนคอมพิวเตอร์และสมาร์ทโฟน โดยมีโครงสร้างและฟีเจอร์ครบถ้วนดังต่อไปนี้: --- ### 1. 🎨 การดีไซน์และส่วนต่อประสานผู้ใช้ (UI/UX - Luxury Black & Gold Theme) - **โทนสีหลัก:** - พื้นหลัง: สีดำลึก (Dark Obsidian/Charcoal #0D0D0D ถึง #121212) มีมิติด้วย Gradient Soft Glow - กรอบ ปุ่ม และไอคอน: สีทองหรูหรา (Metallic Gold Accent #D4AF37 / #FFD700) พร้อมเอฟเฟกต์ Glassmorphic (ความโปร่งแสงเบาๆ) - ตัวหนังสือ: สีขาวมุกและสีทอง - **เลย์เอาต์ระบบ (Layout Structure):** - **Sidebar ด้านซ้าย (พับเก็บได้):** สำหรับตั้งชื่อ AI ส่วนตัว, ตั้งค่า System Persona, ใส่ API Keys, เลือกเสียงอ่านภาษาไทย/อังกฤษ และเมนูเลือกโหมด Multi-Agent - **พื้นที่ตรงกลาง (Chat Interface):** ช่องประมวลผลแชท แสดงข้อความโต้ตอบ กล่องป้อนคำสั่ง ปุ่มฟังเสียงอ่าน (🔊) และปุ่มไมโครโฟนรับเสียง (🎙️) - **พื้นที่ด้านขวา (Interactive Live Preview Canvas):** หน้าต่างพรีวิวโค้ดแอปพลิเคชันแบบ Real-time (Artifacts Canvas) พร้อมปุ่มคัดลอกโค้ดและปุ่มดาวน์โหลดไฟล์ `.html` - **ระบบปรับขนาดภาพ/วิดีโอ (Aspect Ratio Selector):** ปุ่มเลือกอัตราส่วนภาพและวิดีโอ (`1:1`, `9:16`, `16:9`) ก่อนสั่งเจนสื่อ --- ### 2. 🧠 ระบบประมวลผลและสมอง AI (AI Engine & Multi-Agent Personas) - **API หลัก:** รองรับการเชื่อมต่อกับ **Google Gemini API** (ใช้ Gemini 2.5 Flash / Pro) สำหรับประมวลผลคำสั่ง แชท และสร้างโค้ด - **API สำรอง:** รองรับ **Groq API** (Llama 3 / DeepSeek) สำหรับการประมวลผลแชทความเร็วสูง - **ระบบเลือกโหมดผู้เชี่ยวชาญ (Specialized Personas):** 1. *General Assistant:* ผู้ช่วยทั่วไป ชาญฉลาด สดใส 2. *Coding & App Builder:* ผู้เชี่ยวชาญการเขียนโค้ด ให้ส่งโค้ด HTML/CSS/JS ออกมาเพื่อรันใน Live Canvas ทันที 3. *Prompt & Creative Master:* ผู้เชี่ยวชาญการเกลา Prompt สำหรับเจนรูปและวิดีโอ 4. *Content & Marketing Pro:* ผู้เชี่ยวชาญด้านสคริปต์คลิปสั้น สโลแกน และคอนเทนต์ปักตะกร้าขายของ --- ### 3. 🔊 ระบบเสียงอ่านและโหมดคุยแบบ Hands-Free (Full Voice Mode) - **Text-to-Speech (TTS):** ใช้ **Web Speech API** ในเบราว์เซอร์ (ฟรี ไม่ต้องใช้ API Key) มีปุ่มลำโพง (🔊) ข้างทุกข้อความตอบกลับของ AI สามารถกดอ่าน และดึงรายชื่อเสียงภาษาไทย/อังกฤษในเครื่องมาให้เลือกปรับแต่งใน Sidebar ได้ - **Speech-to-Text (STT):** ใช้ **SpeechRecognition API** มีปุ่มไมโครโฟน (🎙️) เมื่อกดพูดจะแปลงเสียงเป็นข้อความลงในช่องแชทให้อัตโนมัติ - **Auto-Continuous Voice Mode:** มีสวิตช์เปิด/ปิด "โหมดคุยเสียงต่อเนื่อง" เมื่อ AI อ่านเสียงจบ ระบบจะเปิดไมโครโฟนรอรับเสียงพูดคำสั่งถัดไปทันทีโดยไม่ต้องเอามือจับเม้าส์ --- ### 4. 🖼️ ระบบสร้างรูปภาพและวิดีโออัจฉริยะ (Smart Media Studio) - **Image Generation Engine:** ดึง **Pollinations.ai API** (`https://image.pollinations.ai/prompt/[prompt]`) สำหรับเจนรูปภาพฟรี 100% ไม่ต้องใช้ API Key - หากผู้ใช้พิมพ์คำสั่งเช่น `/draw [รายละเอียด]` หรือ "วาดรูป..." ให้ AI แปลงเป็น Prompt ภาษาอังกฤษที่สละสลวยแล้วเรียกใช้ API เพื่อแสดงรูปภาพตรงในช่องแชทตามอัตราส่วนที่เลือก (`1:1`, `9:16`, `16:9`) - มีปุ่ม "ขยายเป็นวิดีโอ (Send to Video)" ต่อจากรูปภาพที่เจนเสร็จ - **Video Generation Engine:** รองรับการเจนวิดีโอสั้นฟรีผ่าน Pollinations.ai Video Endpoint หรือ Hugging Face Inference API สามารถเล่นวิดีโอในกล่องแชทได้ทันที --- ### 5. 💾 ระบบความจำระยะยาวและการบันทึกข้อมูล (Long-Term Memory) - ใช้ **LocalStorage / IndexedDB** ในการบันทึก: - ชื่อ AI และ System Persona ที่ผู้ใช้กำหนดเอง - ประวัติการคุยแชทย้อนหลัง (ปิดเว็บแล้วเปิดใหม่ข้อมูลไม่หาย) - สไตล์ความชอบส่วนตัวและไฟล์โค้ดที่เคยเจนไว้ --- ### 6. 🚀 ข้อกำหนดการส่งมอบโค้ด (Output Requirements) - ส่งมอบโค้ดทั้งหมดในไฟล์เดียว (`index.html`) ที่รวมโครงสร้าง HTML, สไตล์ CSS, และสคริปต์ JavaScript ไว้ครบถ้วน - ใช้ CDN สำหรับ Icon (เช่น FontAwesome หรือ Lucide Icons) และ Font (เช่น Google Fonts 'Kanit' หรือ 'Inter') - โค้ดต้องสะอาด อ่านง่าย มีคอมเมนต์อธิบายวิธีนำไปวาง API Key และการเปิดใช้งาน
